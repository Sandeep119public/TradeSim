# TradeSim

A local-first Binance USDⓈ-M futures historical replay and paper-trading simulator. All orders are simulated; the initial app does not place live Binance orders.

## Start

Requires Node.js 20.19+.

```sh
npm install
npm run dev
npm test
npm run build
```

See `docs/ROADMAP.md` for staged development. Never store Binance secrets in the frontend or repository.
